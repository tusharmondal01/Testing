Setting up ComfyUI Desktop
  1. Open ComfyUI Desktop and keep it running while you work. The workflow's models must be installed on it.
  2. In ComfyUI, open Settings and find Server-Config. Set Enable CORS header to https://craftush.netlify.app (or *), then restart ComfyUI.
  3. Use the address http://127.0.0.1:8000 for ComfyUI Desktop, or http://127.0.0.1:8188 for the portable version.
  4. Use Chrome or Edge. If the browser asks to access devices on your local network, click Allow.
